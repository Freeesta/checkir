# Contributing
Italiano: [CONTRIBUTING.it.md](CONTRIBUTING.it.md)

checkIR is data-processing software and a wiki written by its maintainers. Editing the wiki or proposing texts from the site is not available.

| You are… | You can… | Start here |
|---|---|---|
| Anyone | report an error in the program, a text or a result | the [bug form](https://github.com/Freeesta/checkir/issues/new?template=bug.yml) |
| A developer | fix bugs, build features | [docs/contribute/develop.md](docs/contribute/develop.md) |

## Rules for everyone
- Read the [Code of Conduct](CODE_OF_CONDUCT.md).
- See [GOVERNANCE.md](GOVERNANCE.md) for roles and who decides what.
- No personal data in a report or a pull request: no names, contacts, photos, places more precise than a province, dates more precise than a month. Never attach real sample files.
- No synthesis, extraction, potentiation or cutting instructions; no vendors or places to buy substances.
- Licences: code MIT OR Apache-2.0; spectra and data CC BY 4.0; substance sheets CC BY-SA 4.0. You keep your copyright; there is no CLA.
- What is merged into `main` is published. Every statement has a source. The program proposes, the chemist decides, nothing is ever "safe".
- A report needs a free GitHub account (a pseudonym is fine; GitHub sees your IP address and account). What you write is public.

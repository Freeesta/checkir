# Contribution card (spectrum)
Italiano: [card.it.md](card.it.md)

The fields of the "Propose a spectrum" form and of the JSON sheet that checkIR will generate. All are required unless marked optional.

| Field | What to write |
|---|---|
| Substance and form | Name (INN or common name) and form: base, hydrochloride, other salt, hydrate… |
| Confirmation method | Certified standard (with lot number) / another technique (which one) / not confirmed. Spectra with no stated method are not published. |
| Instrument and accessory | For example "FTIR with diamond ATR". **No serial number.** |
| Resolution, scans, range | For example 4 cm⁻¹, 32 scans, 4000–400 cm⁻¹. |
| Month | `YYYY-MM`. Never a more precise date. |
| Author (optional) | Name, pseudonym or service name. Public once published. |
| Licence | Box: I agree that the spectrum is published under CC BY 4.0. |
| Declarations | Boxes: no personal data in the files; I have the right to publish this spectrum; it does not come from a third-party library. |
| Notes (optional) | Only analytical remarks (sample matrix, known cutting agents seen). No places, venues, vendors or people. |

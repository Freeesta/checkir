# Scheda di contributo (spettro)
English: [card.md](card.md)

I campi del modulo «Proponi uno spettro» e della scheda JSON che genererà checkIR. Tutti obbligatori salvo diversa indicazione.

| Campo | Cosa scrivere |
|---|---|
| Sostanza e forma | Nome (DCI o nome comune) e forma: base, cloridrato, altro sale, idrato… |
| Metodo di conferma | Standard certificato (con numero di lotto) / altra tecnica (quale) / non confermato. Gli spettri senza metodo dichiarato non vengono pubblicati. |
| Strumento e accessorio | Per esempio «FTIR con ATR a diamante». **Nessun numero di serie.** |
| Risoluzione, scansioni, intervallo | Per esempio 4 cm⁻¹, 32 scansioni, 4000–400 cm⁻¹. |
| Mese | `AAAA-MM`. Mai una data più precisa. |
| Autore (facoltativo) | Nome, pseudonimo o nome del servizio. Pubblico dopo la pubblicazione. |
| Licenza | Casella: accetto che lo spettro sia pubblicato con licenza CC BY 4.0. |
| Dichiarazioni | Caselle: nessun dato personale nei file; ho il diritto di pubblicare questo spettro; non proviene da una libreria di terzi. |
| Note (facoltative) | Solo osservazioni analitiche (matrice del campione, taglianti noti osservati). Niente luoghi, locali, venditori o persone. |

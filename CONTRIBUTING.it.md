# Contribuire
English: [CONTRIBUTING.md](CONTRIBUTING.md)

checkIR è un software di elaborazione dati e una wiki scritta dai suoi manutentori. Modificare la wiki o proporre testi dal sito non è possibile.

| Sei… | Puoi… | Comincia da qui |
|---|---|---|
| Chiunque | segnalare un errore nel programma, in un testo o in un risultato | il [modulo degli errori](https://github.com/Freeesta/checkir/issues/new?template=bug.yml) |
| Uno sviluppatore | correggere errori, costruire funzioni | [docs/contribute/develop.it.md](docs/contribute/develop.it.md) |

## Regole per tutti
- Leggi il [Codice di condotta](CODE_OF_CONDUCT.it.md).
- Ruoli e chi decide cosa: [GOVERNANCE.it.md](GOVERNANCE.it.md).
- Nessun dato personale in una segnalazione o in una pull request: niente nomi, contatti, foto, luoghi più precisi della provincia, date più precise del mese. Non allegare mai file di campioni reali.
- Niente istruzioni di sintesi, estrazione, potenziamento o taglio; niente venditori o luoghi dove acquistare sostanze.
- Licenze: codice MIT OR Apache-2.0; spettri e dati CC BY 4.0; schede delle sostanze CC BY-SA 4.0. Mantieni i tuoi diritti d'autore; non c'è nessun CLA.
- Ciò che viene unito a `main` è pubblicato. Ogni affermazione ha una fonte. Il programma propone, il chimico decide, niente è mai «sicuro».
- Per segnalare serve un account GitHub gratuito (va bene uno pseudonimo; GitHub vede il tuo indirizzo IP e il tuo account). Ciò che scrivi è pubblico.
